📂 Python File Handling CLI Tool

A simple command-line based Python application to perform basic file operations such as Create, Read, Update, Delete, and Rename files using built-in modules like pathlib and os.

🚀 Features
📄 Create new files with custom content
📖 Read contents of existing files
✏️ Update files:
Rename file
Overwrite file content
Append new content
🗑️ Delete files
📁 Displays all files and folders in the current directory
⚠️ Basic error handling implemented
🛠️ Technologies Used
Python 3
pathlib module
os module

📌 How It Works

When you run the program, it shows a menu:

1 → Create a file  
2 → Read a file  
3 → Update a file  
4 → Delete a file  

Based on your input, the program performs the selected operation interactively.

▶️ Usage
1. Clone the repository
git clone https://github.com/your-username/file-handling-python.git
cd file-handling-python
2. Run the script
python your_script_name.py
💡 Example Workflow
Choose option 1 → Enter file name → Add content → File gets created
Choose option 2 → Enter file name → Content is displayed
Choose option 3 → Rename / overwrite / append content
Choose option 4 → Delete a file
⚠️ Notes
Make sure you enter valid file names
Files are created in the current working directory
No confirmation prompt before deletion (use carefully)
